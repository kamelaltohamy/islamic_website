## 📌 نبذة عن المشروع (About The Project)

بوابة إلكترونية إسلامية شاملة وقالب ووردبريس مخصص لعرض التراث العلمي والدعوي لـ **فضيلة الشيخ الدكتور محمد بن إسماعيل المقدم** (حفظه الله).

يهدف المشروع إلى توفير تجربة مستخدم عصرية، سريعة، ومريحة للقارئ والمستمع المسلم، مع دعم كامل للاتجاه من اليمين إلى اليسار (**RTL**) وتوافق تام مع كافة الهواتف الذكية والشاشات، مع هيكلة محتوى متقدمة تناسب المواد الشرعية (صوتيات، سلاسل، مرئيات، كتب، فتاوى، ومقالات).

---

## ✨ المميزات الرئيسية (Key Features)

- 🎙️ **قسم الصوتيات والسلاسل:** مشغل صوت مدمج يدعم الاستماع المباشر والتحميل، مع تصفح السلاسل والدروس المقسمة.
- 🎥 **قسم المرئيات والمحاضرات:** استعراض مقاطع الفيديو والمحاضرات المصورة مع مشغل مدمج وعرض الدروس ذات الصلة.
- 📖 **المكتبة والكتب:** تصفح الكتب والرسائل والمصنفات العلمية مع خيارات القراءة والتنزيل.
- ⚖️ **بنك الفتاوى والاستشارات:** فهرسة الفتاوى حسب الأبواب الفقهية والتصنيفات الشرعية.
- ✍️ **المقالات والبحوث:** قسم مخصص للمقالات مع خط قراءة عربي أصيل ومريح للعين (**Amiri**).
- 📜 **السيرة الذاتية والمسيرة الدعوية:** صفحة مخصصة تستعرض حياة الشيخ ونشأته وطلبه للعلم ومشايخه ومؤلفاته.
- 🎨 **تصميم حديث وعصري (Tailwind CSS):** هوية بصرية إسلامية رصينة (Deep Sapphire & Islamic Gold) مع سرعة تحميل استثنائية.
- ⚡ **تفاعلية خفيفة (Alpine.js):** تبويبات، قوائم منبثقة، وتفاعلات سريعة دون الحاجة إلى مكتبات ثقيلة.
- 📱 **متجاوب 100% (Responsive):** مواءمة كاملة لكافة الشاشات (الهواتف، الأجهزة اللوحية، الحواسيب).

## 🛠️ التقنيات المستخدمة (Tech Stack)

| التقنية | الاستخدام |
| :--- | :--- |
| **HTML5 & CSS3** | البنية الهيكلية لصفحات القالب |
| **Tailwind CSS** | بناء الواجهات الجمالية والتنسيقات المتجاوبة |
| **Alpine.js** | إدارة التفاعلية اللحظية (Modals, Dropdowns, Tabs) |
| **Google Fonts** | خط **Alexandria** للواجهات والعناوين، وخط **Amiri** للنصوص والقراءة |
| **FontAwesome 6** | الأيقونات التفاعلية والرسومية |
| **WordPress & PHP** | تحويل التصميم إلى قالب ووردبريس تفاعلي متكامل (`almukaddem-theme`) |

## 🚀 كيفية التشغيل والمعاينة (Quick Start)

### 1. معاينة صفحات الـ HTML (Static Preview)
يمكنك فتح أي ملف `.html` مباشرة في المتصفح أو باستخدام خادم محلي خفيف مثل:
- ملحق **Live Server** في VS Code.
- أو عبر بايثون:
  ```bash
  python -m http.server 8000
  ```
  ثم افتح `http://localhost:8000/index.html`.

### 2. تثبيت قالب ووردبريس (WordPress Installation)
1. انسخ مجلد `almukaddem-theme` إلى مجلد القوالب في ووردبريس:
   ```
   wp-content/themes/almukaddem-theme
   ```
2. ادخل إلى **لوحة تحكم ووردبريس > المظهر > قوالب**.
3. قم بتفعيل **قالب موقع الشيخ محمد إسماعيل المقدم**.
